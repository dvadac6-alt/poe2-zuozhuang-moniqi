# 流放之路 2 · 做装模拟器

基于 0.5 版本游戏数据（poe2db / POE2_HTC）的武器做装模拟器，中文界面，本地运行，无需安装。

## 启动

双击 **`启动做装模拟器.bat`** —— 会以独立应用窗口（Edge/Chrome 应用模式，无地址栏）打开。
也可以直接双击 `app/index.html` 用任意浏览器打开。

## 功能

- **分类首页 → 类型 → 基底**：首页按**武器 / 护甲 / 珠宝 / 项链 / 戒指**选购；武器再选类（弓/战矛/…/权杖/盾牌/轻盾等 14 类），护甲再选部位（头盔/胸甲/鞋子/手套/腰带），**防具基底按属性筛选**（纯力量 / 纯敏捷 / 纯智慧 / 力敏 / 力智 / 敏智），项链 / 戒指直接选基底。
- **选部位 → 选基底**：9 类武器 + **法器 / 箭袋** + **戒指（25 基底）/ 项链（71 基底，含 51 个技能项链变体）/ 魔符（31）/ 珠宝 4 类** + **盾牌 122 / 轻盾 41（属武器分类的防御副手）+ 护甲 5 部位（头盔 207 / 胸甲 278 / 鞋子 165 / 手套 168 / 腰带 16）**，共 25 个部位 1433 个基底。**唯一专用基底不收录**（符文之叉、全部「符文师匠」升级形态 —— 它们是传奇专属/符文锻造台产物，无法做装）。防具按基底属性自动分池；**精华一件物品最多 1 条（普通+完美合并上限）**；**首领预兆（黑血/领主/君主）仅限武器/首饰**；**深渊骨头两步流程**（加骨 → 待揭示状态 → 三选一揭示，深渊回响六选一，腐化揭示清空重灌 6 条）。
- **26 种预兆**：升华/剥离/消减/消抹/加冕/炼金/晶化/死灵/首领/深渊回响/**腐化揭示/圣化/祝圣/同质化加冕**；圣化使神圣石数值 ×80-120% 并标记圣化。
- **魔法物品点金**（0.3.1+ 规则）：点金石可用于普通 / 魔法物品，魔法物品重掷为稀有 4 条。
- **深渊骨头**：稀有物品使用后弹出「深渊揭示」候选（普通∪深渊池 3 选 1，深渊回响预兆 6 选 1），首领预兆锁定对应秘藏池。
- **数值面板**：武器 DPS / **防具防御汇总（白值+词缀加成）** / **戒指项链属性汇总（生命·魔力·抗性·属性·速度等）**。
- **做装目标**：设定想要的词缀（搜索添加），roll 中自动高亮 + 提示。
- **两步式通货**：先点选左侧通货（高亮 + 显示结果预测 / 预兆搭配），再点 **「✓ 使用」按钮**生效，避免误触；选中的通货再点一下取消，不可用通货会被禁用并说明原因。
- **八分类通货面板**：左侧做装台按 **通货 / 精华 / 合金 / 涂油 / 符文 / 预兆 / 深渊 / 裂隙** 八个标签分组——通货（蜕变/增幅/富豪/点金/崇高/神圣/混沌/破溃/发辫/剥离 + 催化剂品质）、精华（21 种弹窗选档）、合金（13 种按部位过滤）、涂油（项链注入 + 珠宝蒸馏情感）、符文（镶嵌面板）、预兆（按通货分组全列出，点选挂载）、深渊（渎灵骨 + 档位）、裂隙（裂隙精华 + 创世树入口提示）。
- **完整做装通货**：蜕变 / 增幅 / 富豪 / 点金 / 崇高 / 神圣（重掷词缀数值）/ 混沌 / 破溃宝珠（分裂锁定词缀，免疫剥离与混沌删除）/ 辛格拉的发辫（预示下一个通货效果，可自由应用或放弃，与游戏一致：修改物品才会解除预示）/ 剥离 / 精华（21 种 × 4 级）/ 亵渎通货，全部支持 普通 / 高级 / 完美 分档（高档位只 roll 档位需求 ≥35 / ≥50 的词缀）。
- **全部游戏原图标**：1747 张 poe2db 游戏原画 —— 12 种通货、27 种预兆、21 种精华、13 种合金、26 种蒸馏情感（含远古变体）、**207 张增幅物图标（基础符文 + 魂核）**、1433 个基底插画（武器/防具/首饰全部位，含创世树失神项链，本地打包，离线可用）。图源为 `cdn.poe2db.tw/image/Art/2DItems/...`，缺失素材可按此路径补抓。
- **21 种预兆**：升华（限前缀/后缀/额外词缀）、剥离（限前缀/后缀/光之预兆必删亵渎/**强效一次删 2 条**）、**消减（混沌删等级需求最低词缀）**、**消抹·左/右（混沌只删前缀/后缀）**、**加冕·左/右（富豪只加前缀/后缀）**、**炼金·左/右（点金前缀/后缀拉满）**、晶化、死灵、黑血/领主/君主（限定库尔加尔 / 阿玛纳姆 / 乌拉曼首领池）。
- **消耗统计**：按实际使用数量逐通货计数（如 混沌石×12、剥离石×3），不再做崇高石换算。
- **符文镶嵌（0.5 Augment 全系统）**：装备的增幅器插槽（武器/护甲 2、首饰 1，珠宝 0）可镶嵌三类增幅物，共用插槽 —— ① **基础符文 84 家族 131 种**（元素/属性/守望等，次级/标准/高级/完美品级，按部位给固定加成；武器上的附加元素伤害与物理提高直接计入 DPS 面板）；② **魂核 30 种**（限定部位、每件限 1，如 海幽夏的耐热灵核「+40% 的护甲同样作用于冰霜伤害」）；③ 特殊符文（Runes of Aldur）：瑟尔的凯旋（允许的后缀 +1，稀有 3 前 4 后）、阿斯特丽德的创造（工艺词缀上限 +1）、六颗部位符文解锁专属词缀池（乌崔德的星辰 鞋子·塑时术师 7 条 / 克尔的狩猎 手套·神射手 12 条 / 沃拉娜的屠戮 头盔·盛怒 15 条 / 斯鲁德的神力 武器·毁灭 9 条 / 梅德维德的照料 胸甲·灵魂 21 条 / 卡塔拉的阴霾 手套·腐蚀 14 条）；**巧匠石**可为武器/护甲 +1 插槽（每件 1 次）。数据源 `tools/build_augments.mjs`（poe2db Augment 页中英对齐提取）。
- **谵妄 · 蒸馏情感（0.5）**：26 种蒸馏情感（13 普通 + 13 远古）——对稀有基础珠宝 / 时逝珠宝使用，移除一条随机词缀（优先同侧）并附加保证的**工艺词缀**（按情感 × 珠宝颜色，凶暴/轻蔑可选前后缀变体）；**强效轻蔑**即“+1 允许后缀 / +1 允许前缀”工艺词条。
- **创世树独占底子（0.5 裂隙）**：创世树孕育的 8 个新底子——戒指 生息/动能/活力/幻梦/记忆/贪婪 + 护身符 日冕/失神，自带独占词缀池（召唤/施法/异界三系，仅这些底子可 roll）。
- **时逝（Time-Lost）珠宝**：编年史珠宝类 9 底子之一（**官方名 Time-Lost Ruby / 失落的红玉**，内置隐式「local jewel effect base radius [1000]」）——4 个失落底子 + 184 条“范围内小/核心天赋同时给予…”词缀池，可正常做装；远古蒸馏情感专用目标。
- **合金（0.5 Verisium 残迹）**：13 种合金（符文/适性/防护/扩展/迅捷/飓风/棱镜/神秘/君王/天界/超凡/符文缚者/符文之父）——对稀有物品使用，移除一条随机词缀（优先同侧）并附加该合金对当前部位的**保证词缀**（前缀/后缀按表固定，poe2db 全表 + 中英文）；合金标签按当前部位自动过滤可用项。
- **涂油注入（0.5 枯萎之树）**：3 种有序液体情感为项链注入**专精天赋**（874 条配方全收录，poe2db 中英对齐）——**游戏式界面**：情感托盘（13 种液体情感带图标）点按填入 3 个油槽，填满后自动查找对应专精并显示名称与效果（组合不存在则不显示），可一键注入或清空；下方保留配方搜索浏览。附魔不占词缀位、可覆盖重涂。
- **真实概率引擎**：(词缀 × 档位) 成对加权抽取，与 POE2_HTC 引擎一致 —— 同族互斥、同 ID 互斥、物品等级门控、通货档位下限，右侧面板实时显示下一次操作的完整结果分布（解析概率，非抽样）。
- **武器数值面板**：物理 / 元素 DPS、攻速、暴击实时计算；物品卡片风格贴近游戏内 tooltip。
- **成本与日志**：以崇高石为单位的累计成本（种子估值），逐步日志，支持撤销 / 重置。
- **会话保存**：刷新或关闭后自动恢复做装进度。

```

  index.html           入口页面

  app.js               界面与交互（分类导航 / 做装台 / 弹窗）
  engine.js            概率与做装引擎（与 POE2_HTC 一致的加权抽取）
  stats.js             武器 DPS / 防具防御 / 首饰属性汇总
  i18n_mods.js         词缀中英对齐补译
  data.js              核心数据包（基底 / 通货 / 预兆 / 精华 / 价格 —— 首屏只加载这个，gz ≈ 59KB）
  data_pools.js        词缀池包（mods / 池映射 / 涂油配方 874 条，后台懒加载，gz ≈ 226KB）
  sw.js                Service Worker（静态资源缓存优先 + 后台更新，二次访问秒开、可离线）
  assets.js            本地图标清单（键 → assets/ 路径）
  _icons_preview.html  图标自检页（浏览器打开可逐类核对，开发调试用）
  augments.js           0.5 基础符文 + 魂核数据（build_augments.mjs 生成）
  assets/              1747 张 poe2db 游戏原图（currency / omens / essences /
                       runes / alloys / anointEmotions / augments / weapons 八类，离线可用）
```

## 在新电脑上运行

1. **在线版**：打开 https://dvadac6-alt.github.io/poe2-zuozhuang-moniqi/ —— 浏览器地址栏右侧的「安装」图标（或菜单 → 应用 → 将此站点作为应用安装）可**装成桌面/任务栏图标**，独立窗口启动、秒开、支持离线；手机浏览器「添加到主屏幕」同理。
2. **本地运行**：双击 `启动做装模拟器.bat`（Edge/Chrome 以应用窗口打开，免装任何依赖）；或用任意静态服务器指向 `app/` 目录（如 `python -m http.server -d app`）。
2. **图标核对**：浏览器打开 `app/_icons_preview.html` 可逐类检查图标是否齐全。

## 数据与图标更新

- `app/data.js`（核心）+` app/data_pools.js`（词缀池）由全量包经 `node tools/split_data.mjs` 拆分而来（生成于 2026-09，对应 0.5 版本）；引擎启动时只建核心索引，app.js 首屏渲染后注入词缀池并调用 `ENGINE.loadPools()` 补建。早期提取/打包脚本（`tools/build_data.py` 等）在本仓库 git 历史中。
- 图标源为 `cdn.poe2db.tw/image/Art/2DItems/...`，缺哪张按 `app/assets.js` 清单里的键补抓到对应路径即可（例如基底插画在 `assets/weapons/<类别>/<基底ID>.webp`）。

## 已知简化（与游戏的差异）

- 增幅物按部位生效：poe2db 的「战斗武器 / 法杖或长杖 / 护甲」三分目中，权杖（Sceptres）按施法组处理（与法杖/长杖同组）；羁绊（Bonded）增强效果仅在提示里展示，不参与数值计算；
- 混沌石按引擎建模为「删 1 条 + 加 1 条」，非整件重 roll；
- 混沌系预兆（消减 / 消抹）按 poe2db 0.5 描述建模；**加冕预兆（富豪左右）在 solven-eu 词缀目录中被标注为 0.3 已移除，但 poe2db 0.5 与 CoE 0.5.4 数据仍收录，暂按可用实现，待游戏内核对**；
- 精华对魔法物品按「升级为稀有并追加指定词缀」处理；完美精华按「替换一条同位词缀」处理；
- 强效升华预兆（额外 +1 词缀）上游标记为未验证，界面上以「实验」标注；
- 珠宝（红玉/翡翠/蓝玉/宝钻）按独立词缀池收录，稀有上限 2 前 2 后；**失落（Time-Lost）珠宝与永恒珠宝的特殊词缀池未收录**；珠宝无精华词缀（与数据一致）；
- **防具按基底属性分词缀池**（poolClass 机制）；少数三属性特殊基底（如 Grasping Mail 系列，约 18 个）按混合池近似处理；
- 防具防御数值（护甲/闪避/能量护盾/庇护）为基底白值展示，**词缀带来的防御加成暂未汇总进面板**（不影响词缀 roll 概率）；
- **技能项链变体**：失神（7 种精魄技能）、哀悼（37 种）、预兆（7 种），每个变体独立基底 + 各自隐匿词条；**允许前缀/后缀 ±N 机制已实现**（失神 前-1/后-1、哀悼 前-1、预兆 后-1、暮色/薄暮/半影/暗黑戒指项链 ±1~±2、畸变 -1 前缀、扭曲 -1 后缀），做装时按调整后的上限 roll；
- 基底搜索支持隐匿词缀文本（如搜"大法师"可定位失神项链变体）；防具可**按防御总值排序**；概率面板档位显示数值范围；
- 盾牌/轻盾的移动速度惩罚（-150%/-300%）未在面板展示（不影响词缀 roll）；
- 价格种子估值仍保留在数据中但 UI 不再显示换算；新预兆价格为估值（参考 0.5 市价量级）；
- 破溃宝珠要求稀有物品 ≥4 条词缀（与游戏一致）；
- 狂乱大锤（Fanatic Greathammer）、珠光项链、暮色/薄暮项链的插画在 CDN 上缺失，该基底暂无图；
- **符文镶嵌**：只收录 8 颗做装相关的特殊符文（+1 后缀 / +1 工艺 / 六颗词缀池解锁），基础属性符文（沙漠/冰川/风暴等四档数值符文）、大师符文（升级已镶嵌符文）与卡迪甘的顿悟（插槽转珠宝插槽）未收录；增幅器插槽数简化为武器/护甲 2、首饰 1（珠宝 0）；羁绊（Bonded）词缀需要对应升华激活，仅在提示中说明未参与计算；符文/创世树/时逝词缀的**生成权重 poe2db 未提供**，统一按 1000 均权建模（概率面板的相对占比与游戏可能不同，但可 roll 的词缀集合一致）；
- **蒸馏情感**：词缀表来自 poe2db Liquid Emotions 页整理（2026-09），价格为估值；游戏原文“移除一条随机词缀”近似为**优先移除与工艺词缀同侧**的一条（避免满词缀时流程死锁）；护身符在枯萎柳树注入天赋大点的用法已由「涂油注入」覆盖（见下）；
- **合金**：词缀表来自 poe2db 13 个合金页（2026-09），含未在模拟器收录的武器类（单手剑/斧/匕首/链枷等）时该行自然不命中；游戏原文“移除一条随机词缀”近似为**优先移除同侧**；价格为种子估值；单手剑/双手剑/斧/匕首/链枷等 0.5 新武器类未收录，合金对它们的词条随数据保留但不生效；
- **涂油注入**：874 条配方来自 poe2db Notable 页（2026-09，与 poe2tools 计算器的 874 条完全一致）；有 1 个重复页（Puppet Master chance 两条同名专精，按 slug 去重取后者）；13 种液体情感价格为估值；模拟器允许**重复涂油覆盖**（与游戏一致），不支持移除涂油；
- **创世树**：裂隙腰带（捆扎胎赠）的独占池未收录（仅戒指 + 护身符）；8 个新底子的独占池按部位整体挂载（戒指三系全开），未按底子细分；
- **时逝珠宝**：底子信息（名/图/隐式）取自编年史珠宝类页（2026-09 起原 Time-Lost_Jewels 独立页下线并入 /Jewels）；基底需求等级统一取 20（编年史未标注）；词缀池 184 条为旧静态页抓取（页已下线，提取脚本保留上次数据并提示），远古强效忧郁（半径升级）等无数值词条按固定值处理。
